## Overview

The API security dashboard provides a high-level view of posture, scan activity, and findings across your assets.

<CardGroup cols={2}>
  <Card title="Posture summary" icon="layout-dashboard">
    Review overall API security state across assets and environments.
  </Card>

  <Card title="Finding visibility" icon="shield-alert">
    See where the most important risks are concentrated.
  </Card>

  <Card title="Trend awareness" icon="chart-line">
    Understand whether conditions are improving or getting worse over time.
  </Card>

  <Card title="Actionable follow-up" icon="arrow-right-circle">
    Jump from high-level metrics into the findings and workflows that need attention.
  </Card>
</CardGroup>

## Good usage patterns

- Review the dashboard after each scan cycle
- Compare results across environments
- Use it as an entry point, not a replacement for detailed finding review
