## Overview

Posture tracking helps teams understand whether their API security condition is improving, stagnating, or regressing.

  <Card title="Change awareness" icon="refresh-cw">

  </Card>

  <Card title="Continuous improvement" icon="badge-plus">
    Use scan history to guide long-term security posture work.
  </Card>
