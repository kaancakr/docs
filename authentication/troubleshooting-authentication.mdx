## Overview

Use this page to document the most common authentication setup failures and the steps needed to resolve them.

## Common issue categories

- Invalid or expired tokens
- Incorrect token format or location
- Wrong login parameter mapping
- Missing scopes or unsupported grant types
- Environment mismatches between credentials and APIs
